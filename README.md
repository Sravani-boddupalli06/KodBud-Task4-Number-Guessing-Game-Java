# Number Guessing Game

## Description
This project is a simple Number Guessing Game developed using Java Swing.  
The system generates a random number between 1 and 100, and the user tries to guess the correct number.

The application provides hints such as:
- Too High
- Too Low
- Correct

It also tracks the number of attempts made by the user.

## Features
- Random number generation
- User input through GUI
- Hint messages
- Attempt counter
- Exit option

## Technologies Used
- Java
- Java Swing
- Eclipse IDE

## Concepts Used
- Random Class
- Conditional Statements
- Event Handling
- GUI Development
- Methods and Classes

## Project Structure

NumberGuessingGame.java

## How to Run

1. Open the project in Eclipse IDE
2. Run the NumberGuessingGame.java file
3. Enter a number between 1 and 100
4. Click the Guess button
5. Continue until the correct number is guessed

## Sample Output

- Guess: 20 → Too Low
- Guess: 80 → Too High
- Guess: 50 → Correct!

Attempts are displayed after every guess.
